# DshPanel2 界面优化规格

> 来源：旧面板 `DSH插件/panel/DshPanel/ui/`（index.html 221 行 / style.css 415 行 / app.js 696 行）
> 用途：新会话做界面优化时的对照清单。旧面板的 HTML 结构已完整提取在下面。

---

## 一、总差异

| 维度 | 旧面板 | 当前新面板 | 目标 |
|---|---|---|---|
| 服务页布局 | **双栏**（左插件列表 + 右服务控制/信息） | 单栏堆叠，插件拆成独立页 | 改回双栏 |
| 页面数 | 导航 4 页（服务/设置/日志/关于），插件在服务页里 | 5 页（服务/插件/设置/日志/关于） | 回到 4 页，插件回服务页 |
| 卡片头 | 每个卡片都有 **SVG 图标 + 标题** | 纯文字标题 | 加 SVG 图标 |
| 开关行 | `.srow` = 标题 + **说明副文本** + 开关 | `.row` = 标题 + 开关 | 加说明副文本 |
| 打开方式 | **分段按钮** `.seg`（普通窗口 / 无地址栏独立窗口） | 原生 `<select>` | 改分段按钮 |
| 浏览器选择 | 自定义下拉 `.pick` + `.menu` | 原生 `<select>` | 自定义下拉（可显示勾选态） |
| 关于页 | 居中卡 + **头像 avatar.png** + 版本 + 描述 + 签名 | 纯信息列表 | 恢复头像卡 |

- `.col-main` 左列（插件列表，`card.grow` 撑满高度）

- 服务控制卡里按钮是「主按钮 + 两个图标按钮」，不是四个文字按钮

### 设置页（单栏 scroll）

卡片顺序：**DSH 目录 → 常规 → 网页打开方式 → 服务行为 →（桌宠，已废弃）→ 高级**

关键控件：

```html
<!-- 开关行：标题 + 说明 + 开关 -->
<div class="srow">
  <div><div class="t">开机自启</div><div class="d">登录 Windows 后自动打开这个控制面板</div></div>
  <label class="sw"><input type="checkbox" id="swAutoStart"><i></i></label>
</div>

<!-- 分段按钮 -->
<div class="seg" id="segMode">
  <button data-mode="tab">普通窗口</button>
  <button data-mode="app">无地址栏独立窗口</button>
</div>

<!-- 自定义下拉（能显示勾选态，原生 select 做不到） -->
<div class="pick" id="pickBrowser">
  <button class="btn ghost wide" id="btnPickBrowser"><span id="browserLabel">自动</span><i class="caret"></i></button>
  <div class="menu" id="browserMenu" hidden></div>
</div>
```

三个开关的说明文案（照抄）：
- 开机自启 —— 「登录 Windows 后自动打开这个控制面板」
- 启动服务后自动打开网页 —— 「点「启动并打开 DSH」后自动拉起浏览器」
- 启动后自动最小化到托盘 —— 「面板起来后直接收进通知区域，不打扰你」
- 关闭面板时一并停止 DSH 服务 —— 「不开则关掉面板不影响正在运行的 DSH」
- 服务意外停止时托盘气泡提示 —— 「DSH 自己崩了或被外部杀掉时提醒你」

## 四、新面板**要保留**的改进

这些是旧面板没有的，别在改版时丢掉：

1. **可折叠导航**（`☰` 按钮，190px ⇄ 64px）
2. **CSS 变量主题**（`body.light` 切换，原子生效）
3. **切页 fade 动画**（`.page.active`）
4. **标题栏的画在网页里**（旧版是 WinForms 自绘）
5. **`btn.busy` 扫光动画**（启动中的乐观反馈）
6. **骨架态**：待补

## 五、实施建议

1. **布局先改**：服务页改双栏（`.col-main` / `.col-side`），把插件列表从独立页搬回来
2. **样式再对齐**：从旧 `style.css` 抄组件（`.srow` `.sw` `.seg` `.pick` `.kv` `.card-head` `.ci`）
3. **图标最后加**：内联 SVG 直接复制 path
4. 每步用 `scripts/cdp.mjs shot` 截图对比旧面板

**验证工具**（已就绪）：
```bash
# 面板需带 DSH_PANEL_DEBUG=1 启动
node scripts/cdp.mjs dom                    # 量元素矩形
node scripts/cdp.mjs eval "表达式"          # 查状态
node scripts/cdp.mjs click "#btnX"          # 点按钮
node scripts/cdp.mjs shot "shots/x.png"     # 抓页面像素
```
