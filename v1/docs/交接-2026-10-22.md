## 4. C# ↔ 网页协议

### 网页 → C#（`window.chrome.webview.postMessage`，JSON）

```js
{t:"ready"}                                    // 页面就绪
{t:"nav", page:"service|settings|log|about"}   // 切页（网页里已无导航，此消息仅保留兼容）
{t:"cmd", name:"…", ...}                       // 见下方命令全表
```

`cmd` 的全部 `name`（`PanelUi.cs` 分发）：

| 分类 | 命令 |
| --- | --- |
| 服务 | `start` `stop` `restart` `openWeb` `clean` `clearLog` |
| 界面 | `toggleTheme` `devtools` `exit` |
| 插件 | `togglePlugin` `resetPlugins` |
| 设置 | `setSetting` `setPort` `autoStart` `autoTray` `openOnStart` `stopOnClose` `dev` `notifyCrash` |
| 路径 | `pickDshHome` `probeDshHome` |
| 浏览器 | `pickBrowser` `pickBrowserFile` `setBrowser` |
| 其它 | `openRepo` |
| 桌宠 | `petPatch` `petAction` `petReset` `petPickDir` `petRefresh` |

桌宠相关：
```js
{t:"petPatch",    patch:{...}}     // 改配置，patch 是原始 JSON 片段
{t:"petAction",   action:"toggle-visible|reset-position|see|reload|quit"}
{t:"petReset"}                     // 恢复默认
{t:"petPickDir"}                   // 选 dsh-pet 目录
{t:"petRefresh"}                   // 立即重新探测
```

### C# → 网页（`Host.Post(json)`）

`state` / `plugins` / `paths` / `settings` / `theme` / `toast` / `browsers` / `nav` / `log`，以及桌宠：`pet` / `petSchema` / `petConfig` / `petState` / `petPatched` / `petAction`。

> `Post()` **必须**在 UI 线程调用，已在方法内部加了 `InvokeRequired → BeginInvoke` 的自递归，后台线程直接调是安全的。

## 5. 桌宠接入说明

- 进程发现：`dsh-pet\.state\api.json` → `{port, token, baseUrl, pid}`，**token 每次启动都变**。探测顺序：配置里的 `petdir` → `%LOCALAPPDATA%\dsh-pet` → 从 exe 路径向上 5 层找 `dsh-pet`。判据是 `.state\api.json` 存在。
- 探测频率：2 秒一次 `GET /ping`，只在"上线/下线/换端口"时通知网页，避免刷屏。
- 转发：`/schema` `/config` `/state` `/command` `/config/reset`，一律 `x-pet-token` 头带 token，`PATCH /config` 无 token 会 401。
- **不缓存敏感值**：`visionKey` 这类字段网页用 `type=password` 显示，C# 端只把服务端返回的原样透传，不落盘、不写日志。
- 表单由 `/schema` 的 `groups[]` 动态生成，支持 4 种 `kind`：`number`（滑块 + 数值）、`bool`（开关）、`enum`（分段按钮 + `labels` 中文名）、`string`（输入框）。改字段不用改前端。
- 回读：每次 PATCH 后重新拉 `/config`，所以服务端钳制过的值（如超出 min/max）会立刻反映到界面上。

## 6. 关键技术决策（别改，改了会出事）

### 6.1 DPI：WebView2 用 UseRawPixels 模式

```csharp
// PanelUi.cs 里 Host 的布局部分
Host.BoundsMode = CoreWebView2BoundsMode.UseRawPixels;   // 默认值，写出来是为了明确
// 之后所有位置/尺寸都用 Theme.S 手动 ×S，不能交给 ScaleLayout 再缩一次
Host.Location = new Point(NAV_W * S, TITLE_H * S);       // 物理像素
Host.Size     = new Size((W - NAV_W) * S, (H - TITLE_H) * S);
```
- 逻辑内容区是 812×736，DPI=192 时 `S=2`，物理 2004×1564。
- 试过但**错误**的写法：`Location/Size` 给逻辑值再让 `ScaleLayout` 统一缩放（会被 WebView2 再按 dpr 缩放一次，视口变成一半）；`this.DeviceDpi`（Framework 下恒 96，不可信）。
- 结果验证：页面 `ready` 消息里 `w/h/dpr` 应为 `810×734 dpr=2`。

### 6.2 桌面快捷方式起点

窗口在 `OnLoad` 阶段先挪到 `(-32000,-32000)`，等 WebView2 首次 `NavigationCompleted` 再挪回正确位置。否则用户会看到"黑色空窗口 → 突然刷出界面"的闪烁。**不要**改用 `Opacity` 淡入（WebView2 是独立子 HWND，不受分层 alpha 影响）或 `SetVisibleCore` 拦截（不显示就不触发 Load，直接死锁）。

### 6.3 启动时别设 `WS_EX_COMPOSITED`

历史上加过，导致"打开只渲染一部分、大面积透出后面窗口"，已彻底移除并在代码里留了注释。不要因为"想减少闪烁"再加回来。

## 7. 踩过的坑（都是真事，省点时间）

1. **WebView2 跨线程崩溃**：`InvalidOperationException: CoreWebView2 can only be accessed from the UI thread`。现象是"改完桌宠设置、右击桌宠就崩"。根因是后台探测线程直接调 `Post()`。已修（`InvokeRequired` 自递归）。**任何新加的后台线程回调，只要碰 `_wv`，先过 `Post()`。**
2. **鼠标/键盘注入对 WebView2 基本无效**：`SetCursorPos + mouse_event` 只第一次点击生效，之后点滑块、按方向键全无反应（截图 MD5 不变）。自动化验证滑块类交互只能靠人工，或者临时加"自动切页/自动操作"的调试开关。
3. **单实例 Mutex**：`DshPanel_SingleInstance_v1` 是固定名，用户面板在跑时测试实例会被顶掉。测试要么让用户先退出面板，要么临时加环境变量换 Mutex 名（用完删掉，别留在代码里）。
4. **`/tmp` 在 MSYS bash 与 Windows 程序之间不互通**：node 读不到 bash 写进去的文件，要写到 workspace 内的临时目录。
5. **运行中的 exe 不能直接覆盖**：`Move-Item` 改名成 `.swap`/`.bak` 再复制新的进去，Windows 允许改名不允许覆盖。
6. **`Start-Process` 起 GUI 必须重定向 stdout/stderr**，否则子进程继承管道写端、调用方等 EOF 会一直挂着。
7. **`Timer` 在 `System.Threading` 和 `System.Windows.Forms` 里有歧义**（CS0104），写全名。
8. **`Path` 属性名会遮蔽 `System.IO.Path`**，`PanelConfig` 里已改名为 `FilePath`。
9. **`git push` 在沙箱内会 `Connection was reset`**：需要 `danger-full-access` + `-c http.sslBackend=openssl -c http.sslVerify=false`，token 不能留在 `.git/config` 里；`gh` 走 `_tools\gh\bin\gh.exe` 且必须 `-R ee22ee/dsh-control-panel`。

## 9. 测试方法

- 截图指定进程的窗口：`_t\shotpid.ps1 -ProcId <pid> -Out <png>`（内部用 `PrintWindow ... 2`，能截到 WebView2 内容）。
- 跨进程点击：`_t\clickat.ps1`（全局坐标）。导航项的物理坐标随滚动位置变化，别写死。
- 想看某个页面：临时设环境变量 `DSH_NAVTEST=1`，外壳会每 1.6 秒自动切一页（`PanelUi.BuildContent()` 里），配合连续截图核对四页渲染。
- 状态日志：`%LOCALAPPDATA%\DSH\panel-state.log`，含切页、页面消息、WebView2 初始化失败原因。
- 读桌宠当前值（不依赖 GUI）：
  ```bash
  curl -s http://127.0.0.1:39080/pet/v1/state
  ```
  `PATCH /config` 要带 `x-pet-token`，无 token 返回 401 是正确行为。
